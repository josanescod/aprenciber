# Llistar alumnes de les aules

- afegir la funció per llistar alumnes a  `classroom_repository.py`
- modificar l'esquema `classroom.py`
- afegir l'endpoint a `routes/classrooms.py`
- GET `/api/classrooms/{id}/members` retorna els alumnes de l'aula
- llista el progrés dels alumnes per part del professor.
